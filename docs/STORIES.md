# Implementation Stories

GitHub issues are the source of truth for status. This file keeps the PRD-to-story split visible in the repo.

## MVP Stories

1. Project foundation, PRD, local-only policy, and test harness.
2. Unified watchlist data model with local persistence.
3. TMDb search and metadata services with OMDb score fallback.
4. Add flow with mandatory personal note and Tara interest flag.
5. Watch Now screen with movie/series tabs, filters, hero stack, and ranked list.
6. Status transitions for watched, abandoned, and restore flows.
7. Provider search links that never claim availability.
8. Ranking config files and LLM-backed ranking service with local test fallback.
9. Item detail, metadata source visibility, watched history, and abandoned views.
10. Automated test coverage for acceptance-critical services and flows.

## Backlog Stories

1. Tara sync surface inside `tara.vigneshsundhar.com`.
2. Manual metadata override.
3. Better streaming availability integration.
4. Scheduled re-ranking.
5. Browser extension or share sheet add flow.
